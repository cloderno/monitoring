# Мониторинг цен — Контроль СЗПТ

Мобильное веб-приложение (MVP 1.0) для мониторинга цен на социально значимые продовольственные товары.
Инспектор фотографирует товар вместе с ценником. Gemini распознаёт товар и цену, приложение сравнивает её
с демонстрационным справочником и фиксирует место обследования на карте.

> **Демонстрационная версия.** Учётные записи, ФИО в профиле и справочные цены вымышленные.
> Справочные цены не являются официальными или предельными. История хранится только в браузере.

## Быстрый старт

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env      # вписать GEMINI_API_KEY
npm run dev               # http://localhost:5173
```

`npm run dev` запускает Vite, API (`/api/*`) работает внутри того же процесса.

Production:

```bash
npm run build
npm start                 # http://localhost:3000 (порт — переменная PORT)
```

`server/index.mjs` раздаёт собранный фронтенд и обслуживает API, а также читает `.env`.

## Демонстрационный вход

| Логин       | Пароль      |
|-------------|-------------|
| `inspector` | `szpt2026`  |
| `demo`      | `demo12345` |

При каждом входе для профиля выбирается случайное вымышленное ФИО из списка в `server/users.mjs`.
Пароли хранятся только на сервере в виде scrypt-хэшей. Новый хэш: `npm run hash-password -- <пароль>`.

## Настройки (`.env`)

| Переменная       | Назначение |
|------------------|------------|
| `GEMINI_API_KEY` | Ключ Gemini API ([получить](https://aistudio.google.com/apikey)). Используется только сервером. |
| `GEMINI_MODEL`   | Модель, по умолчанию `gemini-3.8-flash`. |
| `GEMINI_THINKING_LEVEL` | Уровень рассуждений модели, по умолчанию `low` (ответ ~5–10 с). Пусто — настройка модели по умолчанию (до ~50 с). |
| `GEMINI_FALLBACK_MODELS` | Запасные модели через запятую, по умолчанию `gemini-3.5-flash,gemini-3.7-flash`. При перегрузке (503), лимите (429) или недоступности основной модели сервер повторяет запрос и переходит к запасным (общее ожидание не более ~100 с). |
| `AUTH_SECRET`    | Секрет подписи токенов. Если пуст — генерируется при запуске (после перезапуска нужно войти заново). |
| `PORT`           | Порт production-сервера. |

Без `GEMINI_API_KEY` приложение работает, но вместо распознавания предлагает ввести данные с ценника вручную.

## Сценарий

Вход → Приветствие → «Начать обследование» → местоположение (GPS или тестовый Шымкент) → одно фото товара с ценником →
«Распознать и проверить цену» → (при сомнениях — ручное подтверждение) → Результат с картой → История.

### Тестовая геолокация

На экране обследования переключатель «Тестовая геолокация» → «Шымкент (тест)» задаёт фиксированную точку
`42.3417, 69.5901`. GPS при этом не запрашивается. Результат и история помечаются как «ТЕСТОВЫЙ РЕЖИМ».

Реальная геолокация браузера работает только по HTTPS или на `localhost`. Для проверки со смартфона
в локальной сети нужен HTTPS (например, туннель) — либо используйте тестовый режим.

## Как устроено

- **Распознавание** (`server/gemini.mjs`): изображение целиком отправляется в Gemini со строгой JSON-схемой ответа.
  Промпт запрещает придумывать цену, брать её с соседнего ценника или из справочника.
  Ответ проверяется на сервере и повторно на клиенте (`src/services/geminiService.ts`).
  При низкой уверенности (< 0,7), отсутствии цены или товара показывается форма подтверждения.
- **Сопоставление** (`src/utils/productMatching.ts`): нормализация текста + алиасы из `public/products.json`
  и подсказка модели `catalog_id`. Неоднозначный результат требует выбора вручную.
- **Сравнение** (`src/utils/priceComparison.ts`): у каждого товара в справочнике две цены —
  `wholesalePrice` (оптовая закупка) и `retailPrice` (розница). Цена с ценника сравнивается с розницей:
  `difference = shelf − retail`, `percentage = difference / retail × 100`; дополнительно считается наценка
  к оптовой закупке `markup = (shelf − wholesale) / wholesale × 100`. Для товаров «за кг/л» цена упаковки пересчитывается по фасовке
  (например, 900 г). Несовместимые единицы (цена за кг против справочной за упаковку) не сравниваются.
- **Карта**: Leaflet + OpenStreetMap, ссылка «Открыть в Google Maps». Населённый пункт определяется через Nominatim.
- **История**: `localStorage` (до 100 записей с миниатюрами), без синхронизации между устройствами.

## Структура

```text
server/            API: вход, /api/recognize (Gemini), production-сервер
public/products.json  демонстрационный справочник (19 товаров)
src/app            App, маршруты
src/pages          Вход, Приветствие, Обследование, Результат, История, Профиль, Справочник
src/components     шапка, навигация, фото, карта, сравнение цен, форма подтверждения
src/services       API, авторизация, Gemini, геолокация, справочник
src/store          контексты: сессия, история, текущее обследование
src/utils          сравнение цен, сопоставление, изображения, тексты ошибок
src/styles         дизайн-система
```

## Безопасность

- Ключ Gemini и хэши паролей находятся только на сервере и не попадают в клиентский бандл.
- `/api/recognize` требует подписанный токен сессии (HMAC, срок жизни 12 ч).
- Вход ограничен: 10 неудачных попыток за 5 минут с одного IP.
- Перед публичным развёртыванием задайте `AUTH_SECRET` и замените демонстрационные учётные записи.
